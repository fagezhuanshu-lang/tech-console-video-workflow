# 五款审核版复剪记录

2026-11-19，在 Windows 上从新建实例调用各自的作者渲染器，输入审核时的同一段口播和这一版仓库中的五份镜头表。五条新 MP4 均完整解码，视频均为 1080×1920、60 fps、680 帧和 11.33 秒。逐款比较解码后的音频采样，五款均与各自审核片一致，包含本期原声和对应组件的动作音效。

SSIM 是对两条片子所有对应帧计算的画面相似度，1 表示该项比较完全一致。相同镜头表和模板版本仍可能因字体、浏览器、渲染或编码环境产生像素差异。复剪数据来自同一台 Windows 机器。macOS、Linux 及另一台实体电脑尚待实机验证。

## 换素材与原作者效果

仓库提供可在本机生成的彩条视频和测试音。现代图文和活力海报均已用生成的视频与测试音调用个人模板并导出 MP4；可按[快速开始](../README.md)测试自己的环境。

还从独立目录安装了五款技能，逐款用 `--init-timeline` 生成 12 秒入门时间线，换上同一组新的视频和音频。五份时间线均通过各自作者工具的 plan 检查。上表的画面和音轨比较来自实际完整导出的审核片。

原生编舞另用历史正式发行版、逐词字幕和原生参数。作者模板声明的场景数与本次实际导出的场景各有独立记录，详见[原生验证](../native/VERIFICATION.json)与[逐款运行情况](../native/KNOWN-ISSUES.md)。
