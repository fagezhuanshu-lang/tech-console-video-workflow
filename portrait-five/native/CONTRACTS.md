# 五款原生适用合同

五款均是独立 9:16 包，当前声明 1080×1920、60fps；以模板身份和实际包内合同为准。公用读取文档见 README。组数来自作者公开说明，代表可选择组数，不代表本机已逐组验收。

| 入口名 | 适合内容与原生边界 | 必须重点核对 |
|---|---|---|
| modern | 606 现代图文，26 组；观点、证据、过程和归纳 | 文稿的实际数量匹配动作组，保留状态接力；作者主 Demo 仅展示其中 7 组。 |
| paper | 608 纸面透视，41 组；纸卡、资料、步骤、因果、对比与数值 | 原生 `brief.presenter=false` 可隐藏人物窗，但仍要求真实 `media.talk` 与 `media.captions`，不能用空白视频替代。透明示意图只用于实际需要该素材的场景。 |
| dark | 610 深色立体，14 组：9 原生场景、1 独立审阅、4 基础表达 | 多屏素材的 s02→s03 连续接力不能拆断；独立审阅另选对应组；不用虚构性能数据填位。 |
| character | 614 鲜色角色，19 组；叙事、观点与角色关系 | 作者原 25 场中有 12 场未提取；六关键词、二转三、三反馈等只在内容确有该数量时使用。另见 `NATIVE-DEMO.md`：14 秒官方示例只覆盖一组原生 summary，不能作为全模板验收。 |
| poster | 624 活力海报，25 组；大字、清单和图形关系 | 官方 native 与 poster-kit 是不同入口；原生编舞的素材/数量要求以 capacity-matrix 为准。作者仍标注原生连续音画对比、声音等效和极限容量待验证。 |

原生人物路线按 `NATIVE-INPUTS.md` 绑定实际人物视频、原声和字幕。仅有旁白时，已声明的支持路线通常是 motion-kit 或 poster-kit；不要编造原生纯音频开关。组件选择应明确标记并由对应入口执行。

配乐使用本期明确指定的音乐；没有指定时按包内当前音乐接口及许可选用。涉及生成服务时沿用已有明确预算。原声、音乐和动作音效分别检查。原生失败不会自动改变配乐或改用示例人物。

本机完成过五款组件短片全片解码，并已用 610 历史 .14 导出 `03-X:universal-summary` 原生样片。其余历史原生结果见 VERIFICATION.json；任何单组成功均不代表本表全部动作已覆盖。每次新增动作、更新包或换平台，都应记录实际 plan/preview/render 结果和覆盖范围。
