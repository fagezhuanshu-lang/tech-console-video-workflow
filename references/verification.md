# 原版比对

## 先确认输出模式

| 模式 | 比较对象 | 如何检查 |
| --- | --- | --- |
| 认可版（默认） | 已认可的成片 | 检查首帧人物封面、字幕时钟、三种镜头、动作音效和指定配乐。原样片的文件和音视频基线见下表。 |
| 原作者模板直出 | 本次官方实例的原生 MP4 | 比较交付文件与本次原生输出的 SHA-256，两者必须一致。这项检查覆盖全部帧和原生音轨。另行新建实例时，容器信息或渲染细节可能不同。 |

两版可使用同一个 `--source` 和同一份镜头表。 `--original` 仅指使用已认可片段的时间轴。用 `--mode native --original` 可以看这个片段在添加独立封面和配乐之前的效果。

## 认可版样片基线

基线是用户确认的第一版科技控制台试剪。原视频起点为 0，保留 340/30 秒，输出 1080×1920、60 fps、680 帧。第 0 帧是深蓝人物封面。三个原生镜头依次为分栏标题、关键词和引语。音轨为 48 kHz 双声道 AAC，包含现场人声、模板动作音效和已选配乐。

| 可独立比对的文件或流 | SHA-256 |
| --- | --- |
| 原始输入视频 | `ec5172a177d0c250c4e066232fc84894904992feac6f926d6a23fed5d59b38bf` |
| 9:16 原版封面 PNG | `3f2d8a3bf39ac1e51f5ac2c5487decb6349e2fdbeb702423a3cd69c9548457f8` |
| 3:4 原版封面 PNG | `f475d6ca2a9ddb82e66f7c7a5356c1efc3c3d58ea41888c79ce56d8e831fb5c6` |
| 最终 MP4 文件 | `56c9dc3abaf9bdf7897ff0c97f6718fdc034495a8c84a747bc59639774909ae4` |
| 解码视频流 | `b7f8e1e7de5de5e488a03432f11a08fde36cd3820e90137085ede87d08455461` |
| 解码音频流 | `d934a253da0aa73c4921f3db6011ab4d4970c873c8d6fa1b3c3e3eefadb89714` |

在基线 Windows 环境中，公开封面脚本从同一原视频 4.46 秒重新抽取人物画面。两种尺寸的 PNG 和 JPG 均与已交付文件逐字节一致。使用原生画面及其人声/音效、重建的封面和原音床，公开的混音导出脚本通过全片解码，最终 MP4 与基线逐字节一致。

从同一原片和已选 m4a 重建的人物 MP4、人声 WAV 和最终音床 WAV 均与第一次制作时逐字节一致。复验音床的 SHA-256 为 `2ecc7bb090917b6a91f70f43563b8723ed9d6bf0b49a8535f5fc58df0ed630cd`。

在新的个人实例中从头调用官方 612，按同一时间轴重新渲染并完成混音。680 帧的画面结构相似度（SSIM）平均 0.999154，最低 0.996508，第 0 帧为 1.000000。解码音频与原版逐样本完全相同。这个测试复用了已经安装的官方运行依赖。严格的文件复验使用已确认的原生输出，SHA-256 为 `08b44ceac7ec147a66cc45e8309d98f113d58e5f2cd87a324919550991126e42`。

学员自测命令亦已从动态图案、节拍音轨、独立字幕和随包原创配乐通过，实际导出 680 帧并完成全片解码。输入准备另测了 5 秒片段及自备音床。

不同素材用成片的画幅、时钟、三种动效、字幕绑定、动作音效、人声、配乐和双尺寸封面逐项验收。新文案的录音时长、选帧和配乐会改变结果。
